Apresentação do curso

O curso Construindo Ric Bank foi estruturado para estagiários com noções básicas de SQL e distribuído em 12 encontros de 90 minutos. A proposta prioriza prática, resolução de exercícios e contato com cenários próximos da realidade de sistemas bancários.

Durante a trilha, os participantes vão construir e manipular um banco fictício chamado Ric Bank, aplicando comandos básicos, consultas intermediárias, recursos de programação em SQL Server e automação com jobs.

Objetivos de aprendizagem

  • Entender a estrutura de um banco relacional aplicado a um cenário bancário.
  • Revisar comandos essenciais como SELECT, INSERT, UPDATE e DELETE.
  • Utilizar JOINs para combinar dados de tabelas relacionadas.
  • Resolver consultas com subselects.
  • Compreender e criar CTEs simples e recursivas.
  • Aprender o conceito, os benefícios e a construção de stored procedures.
  • Compreender os principais tipos de functions no SQL Server.
  • Criar e interpretar jobs por interface e por T-SQL.
  • Resolver desafios práticos com lógica de negócio bancária.

O banco Ric Bank simula operações comuns de uma instituição financeira. O ambiente inclui cadastro de clientes, gerenciamento de contas, emissão de cartões, controle de transações, empréstimos e auditoria de operações.

Revisão rápida de comandos básicos

SELECT

Utilizado para consultar dados em uma ou mais tabelas. Ao longo do curso, ele será combinado com filtros, ordenação, JOINs, subselects e CTEs.

SELECT Nome, Cidade, UF
FROM dbo.Cliente
WHERE UF = 'PB'
ORDER BY Nome;

INSERT

Utilizado para inserir novos registros nas tabelas.

INSERT INTO dbo.Cliente (Nome, CPF, DataNascimento, Cidade, UF)
VALUES ('Novo Cliente', '99999999999', '2000-01-01', 'Joao Pessoa', 'PB');

UPDATE

Utilizado para atualizar dados existentes. É fundamental validar o filtro antes da execução.

UPDATE dbo.Cliente
SET Telefone = '83988887777'
WHERE ClienteID = 1;

DELETE

Utilizado para excluir registros. Deve ser usado com cautela para evitar remoções indevidas.

DELETE FROM dbo.Cartao
WHERE CartaoID = 999;

JOINs

JOINs são essenciais para relacionar dados distribuídos em várias tabelas. No Ric Bank, serão usados para produzir relatórios e consultas operacionais.

SELECT c.Nome, ct.NumeroConta, a.NomeAgencia
FROM dbo.Cliente c
INNER JOIN dbo.Conta ct ON ct.ClienteID = c.ClienteID
INNER JOIN dbo.Agencia a ON a.AgenciaID = ct.AgenciaID;

Também serão trabalhados cenários com LEFT JOIN para identificar, por exemplo, clientes sem cartão.

Subselects

Subselects permitem usar o resultado de uma consulta dentro de outra. Eles aparecem em comparações, filtros, cálculos e validações.

SELECT *
FROM dbo.Conta
WHERE Saldo > (SELECT AVG(Saldo) FROM dbo.Conta);

CTEs

CTEs ajudam a organizar consultas complexas e a deixar a leitura mais clara. No curso, serão utilizadas para agrupamentos, classificação por faixas e introdução à recursividade.

WITH FaixaSaldo AS (
    SELECT ContaID, NumeroConta, Saldo,
           CASE
               WHEN Saldo < 1000 THEN 'Baixo'
               WHEN Saldo < 5000 THEN 'Medio'
               ELSE 'Alto'
           END AS Faixa
    FROM dbo.Conta
)
SELECT *
FROM FaixaSaldo;

Stored procedures

Stored procedures são blocos reutilizáveis de instruções SQL armazenados no banco de dados. No curso, elas serão tratadas como o principal recurso para encapsular regras de negócio.

  • Recebem parâmetros.
  • Podem devolver dados e status.
  • Permitem reaproveitamento.
  • Organizam operações críticas.

Exemplos no Ric Bank:

  • Procedure para listar transações por conta e período.
  • Procedure para depósito.
  • Procedure para saque com validação de saldo.
  • Procedure para transferência com transação.
CREATE OR ALTER PROCEDURE dbo.usp_Depositar
    @ContaID INT,
    @Valor DECIMAL(18,2)
AS
BEGIN
    SET NOCOUNT ON;

    UPDATE dbo.Conta
    SET Saldo = Saldo + @Valor
    WHERE ContaID = @ContaID;
END;

Functions

Functions serão apresentadas como estruturas reutilizáveis para cálculos e consultas. O curso vai tratar principalmente dois tipos.

TipoUso no curso
Scalar functionCalcular tarifa ou classificação de saldo.
Table-valued functionRetornar extrato resumido ou conjunto de dados reutilizável.
CREATE OR ALTER FUNCTION dbo.fn_CalcularTarifa (@Saldo DECIMAL(18,2))
RETURNS DECIMAL(18,2)
AS
BEGIN
    RETURN CASE WHEN @Saldo >= 5000 THEN 0 ELSE 25 END;
END;

Jobs

Jobs serão estudados em duas frentes: criação pela interface do SQL Server Agent e criação por script T-SQL. O objetivo é mostrar automação real de tarefas operacionais.

  • Execução agendada de procedure de auditoria.
  • Rotina para registrar saldos ou operações do dia.
  • Disparo manual para testes.
EXEC dbo.sp_start_job @job_name = N'Job_Auditoria_RicBank';

Boas práticas em laboratório

  • Sempre validar um SELECT antes de executar UPDATE ou DELETE.
  • Usar nomes claros para procedures e functions.
  • Evitar SELECT * em soluções finais.
  • Organizar scripts por bloco funcional.
  • Registrar dúvidas e soluções para revisão ao final do encontro.

Fechamento

Ao final do curso, o aluno terá praticado a construção de consultas, rotinas reutilizáveis e automações básicas em SQL Server, sempre dentro de um cenário coerente com operações bancárias. O objetivo não é apenas memorizar comandos, mas aprender a resolver problemas de forma estruturada.
